🍴 Forks & Syncing Intermediate

How to copy a project you don't own, keep your copy up to date, and the "fork → PR" model that powers open source.

1 What a fork is (and is not)

A fork is a server-side copy of someone else's repository placed under your own account. You get full write access to your fork while the original ("upstream") is untouched. Forking is GitHub's answer to a simple problem: how do you propose changes to a project you cannot push to? You fork it, change your copy, and open a pull request back.

💡 A fork is different from a clone. Fork = a copy on GitHub under your account. Clone = a copy on your local disk. The usual flow is: fork on GitHub, then clone your fork to your machine.

2 The three repositories in a fork workflow

3 Setting up upstream

# Clone YOUR fork
git clone https://github.com/your-name/project.git
cd project

# Add the original project as a remote called "upstream"
git remote add upstream https://github.com/original-owner/project.git

# Verify both remotes
git remote -v

Now origin points at your fork (you can push) and upstream points at the original (read-only to you).

4 Syncing your fork with upstream

Over time the original project moves ahead and your fork falls behind. Pull in their new commits so your work is based on the latest code:

git fetch upstream
git switch main
git merge upstream/main      # or: git rebase upstream/main
git push origin main         # update your fork on GitHub too

The GitHub web UI also has a one-click "Sync fork" button on your fork's main page that does the same thing without the command line.

⚠️ Always sync before starting new work and before opening a PR, so your branch merges cleanly and does not re-introduce old conflicts.

5 The full contribution loop

  1. Fork the project on GitHub.
  2. Clone your fork and add upstream.
  3. Create a feature branch: git switch -c fix-typo.
  4. Commit, then git push -u origin fix-typo.
  5. Open a pull request from your fork's branch into the upstream repo.
  6. Respond to review, push more commits; the PR updates automatically.
