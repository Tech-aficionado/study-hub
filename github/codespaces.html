☁️ Codespaces Advanced

A full, cloud-hosted dev environment that spins up from your repo in seconds — "it works on my machine" solved.

1 What a Codespace is

A Codespace is a development environment running on a GitHub-hosted container in the cloud, which you reach through VS Code in the browser (or your local VS Code / JetBrains via a connection). The repo is already cloned, the right tools are installed, and nothing touches your laptop. New contributors go from "open repo" to "running code" in under a minute.

2 The dev container (devcontainer.json)

A Codespace is defined by a dev container spec in .devcontainer/devcontainer.json. It pins the base image, tools, VS Code extensions, forwarded ports and setup commands — so everyone gets an identical, reproducible environment.

# .devcontainer/devcontainer.json
{
  "image": "mcr.microsoft.com/devcontainers/javascript-node:20",
  "features": {
    "ghcr.io/devcontainers/features/github-cli:1": {}
  },
  "forwardPorts": [3000],
  "postCreateCommand": "npm install",
  "customizations": {
    "vscode": { "extensions": ["dbaeumer.vscode-eslint"] }
  }
}

3 Creating and using one

  • From the repo: Code → Codespaces → Create codespace on main.
  • From the CLI: gh codespace create, then gh codespace code to open it.
  • Ports your app opens are auto-forwarded with a shareable URL for a quick preview.
  • It is a real Linux box — a terminal, Git, your tools, all pre-set.

4 Lifecycle and cost

Codespaces bill by the minute of compute plus storage, with a monthly free allowance for personal accounts. To control cost: they auto-suspend after an idle timeout, and you should delete ones you no longer need.

gh codespace list
gh codespace stop -c <name>
gh codespace delete -c <name>
⚠️ A stopped codespace still costs storage; a deleted one with uncommitted changes loses them. Commit and push before deleting.

5 When to reach for it

  • Onboarding — contributors skip hours of local setup.
  • Reviewing a PR in a real environment with one click (gh codespace create -r owner/repo -b pr-branch).
  • Working from a locked-down or underpowered machine (iPad, Chromebook).
  • Keeping project toolchains isolated from each other.
💡 The same devcontainer.json also powers VS Code's local "Dev Containers" extension, so the environment is portable beyond Codespaces.
