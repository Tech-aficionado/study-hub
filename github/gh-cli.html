⌨️ gh CLI In Depth Advanced

The official GitHub command-line tool — do almost everything from the terminal, scriptably.

1 Install and authenticate

gh auth login            # interactive: pick HTTPS/SSH, browser or token
gh auth status           # who am I, which scopes
gh auth setup-git        # use gh as the Git credential helper

gh stores a token in your OS keychain and can act as the Git credential helper, so HTTPS pushes just work after login.

2 Repos, PRs and issues

gh repo create my-app --public --source=. --push
gh repo clone owner/repo
gh repo view --web            # open the repo in the browser

gh pr create --fill           # title/body from commits
gh pr status                  # PRs relevant to you
gh pr checkout 42             # fetch & switch to PR #42's branch
gh pr diff 42
gh pr review 42 --approve
gh pr merge 42 --squash --delete-branch

gh issue create --title "Bug" --label bug
gh issue list --assignee @me

3 Actions from the terminal

gh run list                   # recent workflow runs
gh run watch                  # live-tail the latest run
gh run view <id> --log         # full log
gh run rerun <id> --failed     # re-run only failed jobs
gh workflow run deploy.yml -f env=prod   # trigger workflow_dispatch with inputs
gh secret set API_KEY         # reads value from stdin, never shown

4 The raw API and jq-style output

gh api calls any REST or GraphQL endpoint with your auth already attached — the escape hatch for anything the porcelain commands don't cover. --jq filters JSON inline.

gh api repos/{owner}/{repo}/releases/latest --jq '.tag_name'
gh api --paginate /user/repos --jq '.[].full_name'
gh api graphql -f query='{ viewer { login } }'
💡 {owner}/{repo} placeholders are filled in automatically from the repo you're standing in — no need to retype them.

5 Aliases, extensions and scripting

  • Aliases — gh alias set prc 'pr create --fill' makes your own shortcuts.
  • Extensions — gh extension install owner/gh-foo adds community commands; gh extension list shows them.
  • Scriptable — most commands take --json fields for machine-readable output, perfect in CI and shell scripts.
gh pr list --json number,title,author --jq '.[] | "\(.number) \(.title)"'
