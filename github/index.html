🐙 What is GitHub? Beginner

Git is the tool. GitHub is where you host it and work with other people.

1 Git vs GitHub — the distinction people mix up

This trips up almost every beginner: Git is the version control software itself — it works entirely on your own computer, with no internet required. GitHub is a website/service built around Git: it hosts your repositories in the cloud and adds an entire social and collaborative layer on top — pull requests, issue tracking, code review, CI/CD, and more.

💡 You could use Git your whole career without ever touching GitHub. But GitHub (and competitors like GitLab/Bitbucket) is where nearly all real-world team collaboration happens, which is why it matters so much in practice.

2 What GitHub adds on top of plain Git

  • Remote hosting — a durable, always-online copy of your repo, reachable by anyone with access.
  • Pull Requests — a structured way to propose, discuss, and review changes before they merge.
  • Issues — bug tracking and task management tied directly to the code.
  • Actions — automated workflows: run tests, build, deploy, all triggered by Git events.
  • Social layer — stars, forks, followers, the open-source discovery ecosystem.

3 The typical GitHub-based team workflow

Almost every professional team using GitHub follows a version of this loop: branch → commit → push → open a Pull Request → get it reviewed → merge. The sections ahead walk through each piece in depth.
