📋 Quick-Reference Cheatsheet

Key terms, formulas and algorithm steps across all five units — one page, no fluff.

1 Camera models & calibration

Term / FormulaMeaning
x = f·X/Z, y = f·Y/ZPerspective projection — size shrinks with depth Z
x = X, y = YOrthographic projection — no foreshortening
x = f·X/Z̄, y = f·Y/Z̄Weak perspective — perspective scaled by one average depth Z̄
Intrinsic matrix Kfx, fy (focal length), cx, cy (principal point), skew — internal camera geometry
Extrinsics [R | t]Rotation + translation from world frame to camera frame
x = K[R|t]X_wFull projection of a world point to a pixel
Linear calibration (DLT)Closed-form solve via SVD; ignores lens distortion
Non-linear calibrationIterative refinement (Levenberg–Marquardt) minimizing reprojection error; models distortion

2 Feature detection & matching

TermMeaning
Sobel / CannyGradient-based / multi-stage optimal edge detectors (see Unit 2 table for full comparison)
Harris corner responseR = det(M) − k·trace(M)² — large positive R = corner
Ratio testDiscard a match if best-match distance isn't meaningfully better than 2nd-best

3 Stereo vision

Term / FormulaMeaning
Epipolar constraintCorresponding point lies on a single epipolar line, not the whole image
Essential matrix Ep'TEp = 0 — calibrated coords; encodes R, t (5 DOF)
Fundamental matrix Fp'TFp = 0 — pixel coords; F = K'-TEK-1; needs no calibration to estimate
RectificationWarp both images so epipolar lines align to the same horizontal row
Local stereo matchingPer-pixel window correlation (SAD/SSD/NCC) along the scanline; fast, fails on textureless regions
Dynamic programmingOptimal per-scanline disparity path using the order constraint; can streak
Graph cuts / energy minimizationGlobal 2D smoothness + data term; best at discontinuities, costlier
Optical flow constraintIxu + Iyv + It = 0 — brightness constancy, under-constrained (aperture problem)

4 Shape from shading

Term / FormulaMeaning
Image irradiance equationI(x,y) = R(N, L, V) — brightness depends on normal, light, view
Lambertian modelI = ρ·(N·L) — diffuse, view-independent
Specular modelSharp highlight around the mirror-reflection direction; view-dependent
Photometric stereo≥3 images, known different light directions, same viewpoint → solve linearly for N, ρ per pixel
Normal field integrationRecover depth map from normals by integrating gradients (Poisson solve for consistency)
Inter-reflectionIndirect bounced light biases concave regions toward too-shallow depth if ignored
Single-image SfSIll-posed; needs smoothness + boundary-normal constraints to close the gap

5 Structure from motion

TermMeaning
Self-calibrationRecover intrinsics from the image sequence itself, no calibration object needed
Projective ambiguityWithout intrinsics, reconstruction is correct only up to an arbitrary projective transform
Euclidean upgradeKnown/self-calibrated intrinsics + metric reference → true-scale, true-angle reconstruction
Bundle adjustmentJoint non-linear refinement of all camera poses + 3D points, minimizing total reprojection error
Visual SLAMReal-time incremental SfM for robots/AR — build map + localize simultaneously
