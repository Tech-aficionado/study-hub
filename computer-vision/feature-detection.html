🧩 Feature Detection & Matching Unit 2

Finding distinctive, repeatable points in an image — and matching them across views.

1 Edge detection

An edge is a location in an image where brightness changes sharply — typically marking an object boundary, a surface normal change, or a lighting discontinuity. Edge detectors work by estimating the image's intensity gradient: its rate of change in the x and y directions. A strong gradient magnitude signals an edge; the gradient direction gives the edge's orientation.

2 Interest points and corners

Edges alone only localize motion along one direction (you can slide along an edge and the signal stays similar). An interest point — most often a corner, where two edges meet — is distinctive in every direction, making it far more useful for matching between images. The Harris corner detector formalizes this: it looks at how the local image patch's sum-of-squared-differences changes when shifted in any direction, captured by the second-moment (structure tensor) matrix built from image gradients. A corner is flagged where both eigenvalues of that matrix are large (the image changes a lot in every direction); an edge has one large and one small eigenvalue; a flat region has both small.

The Harris response function R = det(M) − k·trace(M)² avoids computing eigenvalues directly — large positive R marks a corner, large negative R marks an edge, small |R| marks a flat region.

3 Local image features & feature matching

A local feature pairs a detected keypoint's location with a descriptor — a compact numerical summary of the image patch around it (e.g. a gradient-orientation histogram) designed to stay similar for the same physical point even if the viewpoint, scale, or lighting changes. Feature matching then compares descriptors across two images (typically with Euclidean or Hamming distance) to find corresponding points — the raw material for panorama stitching, 3D reconstruction, object recognition and tracking.

A common refinement is the ratio test: for each descriptor, compare the distance to its best match against the distance to its second-best match. If the best match isn't meaningfully better than the second-best, the match is ambiguous and discarded — this single trick removes most false matches in practice.

4 Hough Transform

The Hough Transform detects parametric shapes (classically lines, also circles and ellipses) by having every edge pixel "vote" for every shape it could be part of, in a parameter space (an accumulator array) rather than image space. For a line in slope-intercept-free polar form ρ = x·cosθ + y·sinθ, each edge point traces a sinusoidal curve in (ρ, θ) space; points that lie on the same real line in the image cause their curves to intersect at one (ρ, θ) cell, which accumulates votes. Peaks in the accumulator correspond to detected lines. Its strength is robustness to gaps and noise — a line is still found even if parts of it are occluded, because the votes from the visible segments still pile up at the same peak.

5 Model fitting and RANSAC

Real correspondence sets always contain outliers — wrong matches from repeated textures, noise, or occlusion. RANSAC (RANdom SAmple Consensus) fits a model (e.g. a homography or fundamental matrix) robustly in their presence:

  1. Randomly sample the minimum number of correspondences needed to define the model (e.g. 4 points for a homography).
  2. Fit the model to that minimal sample.
  3. Count how many of the remaining correspondences agree with this model within a distance threshold — these are the inliers, and the count is the model's consensus.
  4. Repeat for many random samples; keep the model with the largest inlier set.
  5. Optionally refit the final model using all inliers (e.g. via least squares) for a more accurate result.
💡 RANSAC's key insight: a model fit from a sample of pure outliers will NOT be agreed with by other outliers (they're random), but a model fit from a sample of pure inliers WILL be agreed with by the other true inliers. Enough random trials, and the correct model simply accumulates the most votes.

6 Scale invariant feature matching (SIFT)

SIFT (Scale-Invariant Feature Transform) is the classic algorithm for detecting and describing keypoints that remain recognizable across scale, rotation, and moderate illumination/viewpoint change. Its pipeline:

  • Scale-space extrema detection — build a Difference-of-Gaussians (DoG) pyramid across multiple scales (octaves); candidate keypoints are local extrema across both space and scale, which makes them inherently scale-invariant.
  • Keypoint localization — refine candidate locations and discard low-contrast or poorly-localized (edge-like) points using a Hessian-based test similar in spirit to Harris.
  • Orientation assignment — compute the dominant gradient orientation in the keypoint's local neighborhood and rotate the description relative to it, giving rotation invariance.
  • Descriptor generation — build a 128-dimensional vector from gradient-orientation histograms over a 4×4 grid of sub-regions around the keypoint, normalized for partial illumination invariance.

SIFT descriptors from two images can then be matched (nearest-neighbor + ratio test) and fed into RANSAC to robustly estimate a geometric relationship (homography, fundamental matrix) between the views.
