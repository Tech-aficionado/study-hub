➕ Set Operations Intermediate

Combining the results of two queries vertically — UNION, INTERSECT, EXCEPT — treating result sets like mathematical sets.

1 The three set operators

OperatorReturns
UNIONAll rows from both, duplicates removed
UNION ALLAll rows from both, duplicates kept (faster — no de-dup pass)
INTERSECTOnly rows appearing in BOTH queries
EXCEPTRows in the first query but NOT the second (MINUS in Oracle)

2 UNION vs UNION ALL

SELECT city FROM customers WHERE country = 'Germany'
UNION
SELECT city FROM customers WHERE country = 'France';
-- de-duplicated list of cities across both countries

SELECT 'active' AS kind, COUNT(*) FROM users WHERE deleted_at IS NULL
UNION ALL
SELECT 'deleted', COUNT(*) FROM users WHERE deleted_at IS NOT NULL;
-- UNION ALL keeps both rows (they're different anyway) and skips the de-dup pass
💡 Default to UNION ALL unless you specifically need duplicates removed. Plain UNION does an extra sort/hash to de-duplicate, which costs time on large results.

3 The column-matching rules

Set operators stack results vertically, so both queries must agree on shape:

  • Same number of columns.
  • Compatible types, position by position (column 1 with column 1, etc.).
  • Column names come from the first query; the second query's names are ignored.
⚠️ The match is by position, not by name. SELECT name, city … UNION SELECT city, name … compiles but silently mixes the columns up. Line them up carefully.

4 INTERSECT and EXCEPT in practice

-- Customers who ordered in BOTH 2023 and 2024
SELECT customer_id FROM orders WHERE order_date < '2024-01-01'
INTERSECT
SELECT customer_id FROM orders WHERE order_date >= '2024-01-01';

-- Products that have NEVER been ordered
SELECT id FROM products
EXCEPT
SELECT product_id FROM order_items;
🛑 MySQL added INTERSECT and EXCEPT only in version 8.0.31 (2022). On older MySQL, emulate INTERSECT with an INNER JOIN/IN and EXCEPT with NOT IN/NOT EXISTS. PostgreSQL and SQLite have supported all three for years.

5 ORDER BY applies to the whole result

SELECT name, price FROM products WHERE category_id = 1
UNION ALL
SELECT name, price FROM products WHERE category_id = 2
ORDER BY price DESC;   -- a single ORDER BY at the very end sorts the combined result
