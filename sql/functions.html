2 Numeric functions

ROUND(3.14159, 2)      -- 3.14
CEIL(4.1)   FLOOR(4.9) -- 5 and 4
ABS(-7)                -- 7
MOD(10, 3)  -- 1   (also: 10 % 3)

CAST(price AS INTEGER) -- type conversion
⚠️ Integer division: in PostgreSQL and SQLite, 5 / 2 = 2 (both operands are integers). Cast one side to get 2.5: 5 * 1.0 / 2 or CAST(5 AS REAL) / 2. MySQL's / always returns a decimal; use DIV for integer division.

4 NULL handling: COALESCE and NULLIF

-- COALESCE returns the first non-NULL argument — a "default if missing"
SELECT name, COALESCE(phone, 'no phone on file') AS phone FROM customers;

-- Use it to turn NULL sums into 0
SELECT COALESCE(SUM(total), 0) FROM orders WHERE customer_id = 999;

-- NULLIF returns NULL if the two args are equal — classic guard for divide-by-zero
SELECT revenue / NULLIF(orders_count, 0) AS avg_order_value FROM stats;
💡 NULLIF(x, 0) turns a zero denominator into NULL; dividing by NULL yields NULL instead of a divide-by-zero error. Wrap it in COALESCE(..., 0) if you want a 0 result instead of NULL.

5 CAST and type conversion

SELECT CAST('2024-01-15' AS DATE);        -- standard, works everywhere
SELECT '2024-01-15'::date;                 -- PostgreSQL shorthand
SELECT CAST(price AS CHAR);                 -- number → text
