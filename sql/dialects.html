🔀 Dialect Differences Intermediate

The core SQL is portable; the edges aren't. One reference for the SQLite vs PostgreSQL vs MySQL gotchas scattered across this course.

2 String & concatenation

TaskPostgreSQLMySQLSQLite
Concatenatea || bCONCAT(a, b) (|| = OR!)a || b
Case-insensitive LIKEILIKELIKE (collation-dependent)LIKE (ASCII only)
Quote identifier"col" (double quotes)`col` (backticks)"col" or `col`
String literal'text' (single quotes only)'text' or "text"'text'
⚠️ Double quotes mean an identifier (column/table name) in standard SQL and PostgreSQL, but can mean a string in MySQL's default mode. Always use single quotes for string values to stay portable.
