🎮 SQL Playground

A real SQLite database running entirely in your browser (via WebAssembly). Nothing is sent anywhere — edit, run, break, and reset freely.

1 How to use it

  • Type SQL in the editor and press Run (or Ctrl/Cmd + Enter). Multiple statements run in sequence; each result shows as its own table with a row count and timing.
  • Click a table or column in the schema browser to insert its name at the cursor.
  • Click an example to load and run it. Your past queries live in History.
  • Reset DB restores the original sample data. Save/Load persists your database to this browser's local storage. CSV on any result downloads it.
💡 The sample database models a small shop + HR system: customers, orders, order_items, products, categories, employees (with a manager_id self-reference), and departments — a few hundred rows, deterministic every load.
