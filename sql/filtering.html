🔎 Filtering in Depth Beginner

Everything you can put after WHERE — pattern matching, ranges, lists, NULL logic, and inline conditionals.

1 LIKE and pattern matching

WHERE name LIKE 'A%'      -- starts with A   (% = any run of characters)
WHERE name LIKE '%son'    -- ends with "son"
WHERE name LIKE '%a%'     -- contains an "a"
WHERE code LIKE 'A_C'     -- A, any ONE char, C   (_ = exactly one character)
DialectCase-insensitive match
PostgreSQLILIKE, or ~* for regex
MySQLLIKE is case-insensitive by default (depends on column collation)
SQLiteLIKE is case-insensitive for ASCII only
⚠️ A leading-wildcard pattern (LIKE '%foo') can't use a normal B-tree index, so it scans the whole table. For real text search, use full-text indexes (Postgres tsvector, MySQL FULLTEXT, SQLite FTS5).

2 IN, NOT IN, and BETWEEN

WHERE category_id IN (1, 2, 5);              -- matches any value in the list
WHERE country NOT IN ('US', 'CA');
WHERE price BETWEEN 20 AND 100;              -- inclusive on BOTH ends: 20 ≤ price ≤ 100
WHERE order_date BETWEEN '2024-01-01' AND '2024-03-31';
🛑 NOT IN with a subquery that can return NULL is a notorious trap: if the list contains a NULL, NOT IN returns no rows at all (because "x ≠ NULL" is unknown). Prefer NOT EXISTS when NULLs are possible.

3 NULL — the three-valued logic

SQL logic has THREE values: true, false, and unknown. Any comparison with NULL yields unknown, and WHERE keeps only rows that are true.

WHERE phone IS NULL;        -- correct
WHERE phone IS NOT NULL;
WHERE phone = NULL;         -- WRONG — always unknown, matches nothing

4 CASE — inline if/else in a query

SELECT name, price,
  CASE
    WHEN price >= 100 THEN 'premium'
    WHEN price >= 30  THEN 'mid'
    ELSE 'budget'
  END AS tier
FROM products;

-- CASE is also powerful inside aggregates ("conditional counting"):
SELECT
  COUNT(*) AS total,
  SUM(CASE WHEN status = 'shipped' THEN 1 ELSE 0 END) AS shipped
FROM orders;
💡 The SUM(CASE WHEN … THEN 1 ELSE 0 END) pattern (a.k.a. "pivot by hand") counts rows matching a condition in the same pass — the backbone of turning rows into columns.
