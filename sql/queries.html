🔍 Basic Queries Beginner

SELECT, WHERE, ORDER BY, LIMIT — the core four you'll write constantly.

1 SELECT — choosing what to see

SELECT * FROM users;
-- Every column, every row — fine for exploring, avoid in production code

SELECT name, email FROM users;
-- Only the columns you actually need — faster, clearer

2 WHERE — filtering rows

SELECT * FROM users WHERE age >= 18;

SELECT * FROM orders WHERE status = 'shipped' AND total > 100;

SELECT * FROM users WHERE email LIKE '%@gmail.com';
-- % is a wildcard: matches any characters

SELECT * FROM products WHERE category IN ('books', 'electronics');

SELECT * FROM users WHERE deleted_at IS NULL;
-- NULL means "no value" — you can't compare it with = , must use IS NULL
⚠️ NULL = NULL evaluates to NULL (not true!) in SQL — NULL means "unknown," and unknown compared to unknown is still unknown. Always use IS NULL / IS NOT NULL.

3 ORDER BY and LIMIT

SELECT * FROM products ORDER BY price DESC;
-- Highest price first. ASC is the default if omitted.

SELECT * FROM products ORDER BY price DESC LIMIT 10;
-- Top 10 most expensive products

SELECT * FROM products ORDER BY price DESC LIMIT 10 OFFSET 20;
-- Skip the first 20, then take the next 10 — classic pagination

4 Modifying data: INSERT, UPDATE, DELETE

INSERT INTO users (name, email) VALUES ('Ana', 'ana@example.com');

UPDATE users SET email = 'new@example.com' WHERE id = 42;

DELETE FROM users WHERE id = 42;
🛑 UPDATE and DELETE without a WHERE clause affect EVERY row in the table. This is the single most common catastrophic SQL mistake — always double-check your WHERE before running these in production.
