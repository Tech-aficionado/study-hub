🧪 Labs Hands-on

Progressive challenges against the playground's sample database. Try each yourself first, then expand the solution.

1 How to run these

Open the SQL Playground in another tab. Each lab is written against the sample schema (customers, orders, order_items, products, categories, employees, departments). Paste your attempt, run it, then open the solution to compare.

💡 There's usually more than one correct query. If your result rows match, you solved it — even if your SQL differs from the sample solution.

2 Lab A — Filtering & sorting (beginner)

Task: list the 5 most expensive products in the Electronics category (id 1), showing name and price, highest first.

Show solution 
SELECT name, price
FROM products
WHERE category_id = 1
ORDER BY price DESC
LIMIT 5;

3 Lab B — Aggregation (beginner/intermediate)

Task: for each order status, show how many orders have that status, ordered from most common to least.

Show solution 
SELECT status, COUNT(*) AS n
FROM orders
GROUP BY status
ORDER BY n DESC;

4 Lab C — Joins (intermediate)

Task: show each customer's name and their total number of orders, including customers with zero orders (they should show 0, not be dropped).

Show solution 
SELECT c.name, COUNT(o.id) AS orders
FROM customers c
LEFT JOIN orders o ON o.customer_id = c.id
GROUP BY c.id, c.name
ORDER BY orders DESC;

Key points: LEFT JOIN keeps zero-order customers; COUNT(o.id) (not COUNT(*)) correctly counts 0 for them, because COUNT ignores NULLs.

5 Lab D — Subquery / revenue (intermediate)

Task: find the total revenue (sum of quantity * unit_price) for each order, and show only the orders whose revenue is above the average order revenue.

Show solution 
WITH order_rev AS (
  SELECT order_id, SUM(quantity * unit_price) AS revenue
  FROM order_items
  GROUP BY order_id
)
SELECT * FROM order_rev
WHERE revenue > (SELECT AVG(revenue) FROM order_rev)
ORDER BY revenue DESC;

6 Lab E — Window functions (advanced)

Task: for each department, list the top 2 highest-paid employees with their name, salary, and rank within the department.

Show solution 
WITH ranked AS (
  SELECT name, department_id, salary,
    DENSE_RANK() OVER (PARTITION BY department_id ORDER BY salary DESC) AS rk
  FROM employees
)
SELECT department_id, name, salary, rk
FROM ranked
WHERE rk <= 2
ORDER BY department_id, rk;

Using DENSE_RANK keeps ties together without gaps. Swap in ROW_NUMBER if you want exactly 2 rows per department even on ties.

7 Lab F — Recursive CTE (advanced)

Task: show the management chain depth — every employee with how many levels of management sit above them (the CEO is level 1).

Show solution 
WITH RECURSIVE chain AS (
  SELECT id, name, manager_id, 1 AS level
  FROM employees WHERE manager_id IS NULL
  UNION ALL
  SELECT e.id, e.name, e.manager_id, c.level + 1
  FROM employees e JOIN chain c ON e.manager_id = c.id
)
SELECT level, name FROM chain ORDER BY level, name;
