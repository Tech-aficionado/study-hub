🚀 Indexes & EXPLAIN Advanced

Why one query is instant and another crawls — and how to read the plan the database actually chose.

1 The B-tree index

Most indexes are B-trees — a balanced tree that keeps keys sorted so the engine can binary-search instead of scanning. Finding a row goes from O(n) (read every row) to O(log n) (a few hops down the tree).

2 Creating indexes

CREATE INDEX idx_orders_customer ON orders(customer_id);  -- speeds WHERE/JOIN on customer_id
CREATE UNIQUE INDEX idx_users_email ON users(email);       -- also enforces uniqueness
CREATE INDEX idx_orders_cust_date ON orders(customer_id, order_date);  -- composite
💡 Composite index column order matters. An index on (customer_id, order_date) helps queries filtering on customer_id alone, or both — but NOT order_date alone (the "leftmost prefix" rule). Order the most-filtered column first.

3 The cost side — indexes aren't free

  • Every INSERT/UPDATE/DELETE must also update each index on that table — more indexes = slower writes.
  • Indexes take disk space (sometimes as much as the table).
  • A low-selectivity index (e.g. a boolean with 50/50 split) is often ignored by the planner — scanning is cheaper than the index round-trips.
⚠️ Wrapping an indexed column in a function usually disables the index: WHERE LOWER(email) = 'x' can't use a plain index on email. Use a functional/expression index (CREATE INDEX … ON users(LOWER(email))) or store the normalised value.

4 EXPLAIN — reading the plan

-- PostgreSQL: estimate only
EXPLAIN SELECT * FROM orders WHERE customer_id = 42;
-- PostgreSQL: actually run it and show real timings
EXPLAIN ANALYZE SELECT * FROM orders WHERE customer_id = 42;

-- MySQL
EXPLAIN SELECT ...;      -- 'type' column: const/ref = good, ALL = full scan

-- SQLite (works in this site's playground)
EXPLAIN QUERY PLAN SELECT * FROM orders WHERE customer_id = 5;

💡 Workflow: run EXPLAIN ANALYZE, spot the slow full scan, add the index it needs, re-run, and confirm the plan switched to an index scan with lower cost. Measure — don't guess which index helps.
