🔢 Data Types Beginner

Every column has a type. The categories are universal; the exact names differ by dialect — and SQLite is the odd one out.

1 The universal categories

  • Integers — whole numbers (ids, counts, quantities).
  • Exact decimals — money and anything where rounding matters (NUMERIC/DECIMAL).
  • Floating point — approximate reals for science/measurements (REAL, DOUBLE).
  • Text — strings, fixed or variable length.
  • Boolean — true/false.
  • Date & time — dates, timestamps, intervals.
  • Binary — raw bytes (BLOB, bytea).
  • Structured — JSON, arrays, UUID, and other modern extras.

3 SQLite is dynamically typed — the big surprise

Every other SQL engine is statically typed: a column declared INT only ever holds integers. SQLite is different — the type lives with the value, not the column. A column has a type affinity (a preference), but can store any of five storage classes: NULL, INTEGER, REAL, TEXT, BLOB.

⚠️ Rules are checked in order, so FLOATING POINT gets INTEGER affinity (it contains "INT"!), and STRING gets NUMERIC (no match). Since v3.37 you can use CREATE TABLE … STRICT for rigid typing. Source: sqlite.org/datatype3.

4 Money: never use floating point

Floating-point types can't represent 0.1 exactly, so sums drift by fractions of a cent. For currency, always use the exact decimal type.

-- PostgreSQL / MySQL: exact to the cent
price NUMERIC(10, 2)    -- up to 10 digits, 2 after the decimal point

-- Wrong for money — rounding errors accumulate:
price DOUBLE PRECISION  -- avoid for currency

5 Dates & times: store in UTC, with time zone where you can

In PostgreSQL, prefer timestamptz (timestamp with time zone) — it stores an absolute point in time. MySQL's TIMESTAMP is UTC-based (converts on read) while DATETIME is a wall-clock value with no zone. SQLite stores dates as ISO-8601 text and provides date functions.

-- PostgreSQL
created_at TIMESTAMPTZ NOT NULL DEFAULT now()

-- MySQL
created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP

-- SQLite (text, ISO-8601)
created_at TEXT NOT NULL DEFAULT (datetime('now'))
💡 A naive timestamp with no zone marker is parsed as local time by most clients — the classic bug where a UTC value shows up hours off. Store absolute instants and format for display at the edge.
