⚠️ Three notes on the poster:
  • In section 2, "Insert data" reads CREATE INTG users (...). The correct statement is INSERT INTO users (name, email, age) VALUES (...);
  • The join examples select o.order_date, but the sample orders table has no such column (it has id, user_id, product). Use o.product to run them against that table.
  • The poster uses MySQL commands (SHOW DATABASES, mysqldump), but MySQL has no FULL JOIN. That example works in PostgreSQL and SQL Server; in MySQL you combine a LEFT and a RIGHT JOIN with UNION.
