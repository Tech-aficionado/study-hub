🕹️ Kubernetes Playground Interactive

A simulated cluster in your browser. Run real kubectl commands, watch Pods appear on nodes, and clear the challenges. Nothing here touches a real machine.

1 How to use it

  • Type a command and press Enter (or tap Run on mobile).
  • Core: kubectl get pods|deploy|rs|svc|nodes|ns|cm|secrets|endpoints|all (with -n, -A, -o wide, -o yaml, -l, --show-labels), describe, create deployment, expose, scale, set image, rollout status|history|undo, delete, logs, exec, label, run, apply -f -.
  • Tab completes, ↑ / ↓ recall history, help or help <cmd> for reference.
  • Break things on purpose: an image containing notexist → ImagePullBackOff; kubectl run bad --image=busybox -- exit 1 → CrashLoopBackOff; a Pod with a huge CPU request (via the YAML pane) → Pending + FailedScheduling.

3 Live cluster

4 YAML editor — kubectl apply -f -

Edit the manifest below and press Apply YAML. Supports Deployment, Service, ConfigMap and Pod (a 2-space-indented subset). A missing selector, or a selector that doesn't match the template labels, is rejected just like the real API server.

💡 Try breaking it: change the Service selector to app: web and apply — the Service will show NO ENDPOINTS because no Pod carries that label. Or set the template labels to not match the Deployment selector to see the validation error.

    6 A worked starter sequence

    kubectl create deployment web --image=nginx --replicas=3
kubectl get pods -o wide
kubectl expose deployment web --port=80 --type=NodePort
kubectl get svc
kubectl describe svc web            # see the Endpoints line
kubectl scale deployment/web --replicas=5
kubectl set image deployment/web web=nginx:1.27
kubectl rollout history deployment/web
kubectl delete pod <one-of-the-pod-names>   # watch it get recreated
