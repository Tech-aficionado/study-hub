🌱 Branching & Merging Intermediate

Branches are just movable pointers to commits — that's the whole secret to why they're so cheap.

1 What a branch actually is

A branch is NOT a copy of your files. It's just a tiny file holding the ID (hash) of one specific commit — a few dozen bytes, nothing more. When you commit on a branch, that pointer just moves forward to the new commit. This is why creating a branch is instant, no matter how big your project is.

git branch feature-login
# Creates the branch — does NOT switch to it

git checkout feature-login
git switch feature-login     # newer, clearer command, same effect

git checkout -b feature-login
git switch -c feature-login  # create AND switch in one command

git branch
# List all local branches, * marks the current one

2 Merging: combining two branches

git merge brings another branch's commits into your current branch. If the two branches changed different lines, Git merges automatically. If they changed the same lines, you get a merge conflict — Git marks the conflicting section in the file and asks you to decide.

git switch master
git merge feature-login
# Brings feature-login's commits into master

# If there's a conflict, the file looks like:
<<<<<<< HEAD
your version of the line
=======
their version of the line
>>>>>>> feature-login

# Edit the file to resolve it, remove the markers, then:
git add resolved-file.txt
git commit
A merge conflict is NOT an error you did something wrong — it just means Git genuinely cannot decide, and you have the context it doesn't.

3 Rebase: the "replay" alternative to merge

git rebase takes your branch's commits and replays them one by one on top of another branch, as if you'd started from there all along. The result is a straight line of history, no merge commit.

git switch feature-login
git rebase master
# Replays feature-login's commits on top of master's latest commit
⚠️ Golden rule: never rebase a branch that someone else has already pulled/based work on. Rebase REWRITES commit history (new hashes), so anyone with the old commits will have a confusing, diverged history.
