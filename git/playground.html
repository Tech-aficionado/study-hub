🕹️ Git Playground Interactive

A real-ish Git simulator in your browser. Type commands, watch the commit graph redraw after every one, and clear the guided challenges. Nothing here touches your real machine.

1 How to use it

  • Type a command and press Enter (or tap Run on mobile).
  • Shell: ls, cat <file>, touch <file>, echo "text" > file, echo "text" >> file, rm <file>, clear.
  • Git: init, status, add, restore, commit, log, diff, branch, switch/checkout, merge, rebase, reset, revert, cherry-pick, stash, tag, reflog.
  • Tab completes commands; ↑ / ↓ recall history; help or help <cmd> for reference.

2 Terminal

git-playground — simulated shell
git>

3 Live commit graph

Purple = ordinary commit · red outline = HEAD · gold outline = merge commit (two parents). Branch and tag labels sit above the commit they point to.

4 Guided challenges

Each ticks itself ✅ automatically when your commands satisfy it.

    5 A worked starter sequence

    git init
echo "hello world" > readme.txt
git add .
git commit -m "first commit"
git switch -c feature
echo "feature code" > app.js
git add .
git commit -m "add app"
git switch main
git merge feature          # fast-forward
git log --oneline --graph --all
    💡 Then try breaking things on purpose: make the same line differ on two branches and merge to see a real CONFLICT with markers, resolve it with add + commit, or git reset --soft HEAD~1 to undo a commit while keeping the work.
