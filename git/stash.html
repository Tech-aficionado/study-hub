📦 Stashing Work Intermediate

A shelf for half-finished work when you need a clean tree right now — and how to get it back without surprises.

1 The problem stash solves

You're mid-change on a feature when an urgent bug comes in. Your work isn't ready to commit, but you need a clean working directory to switch branches. git stash tucks your uncommitted changes onto a stack and resets your tree to the last commit — instantly clean.

git stash
# Shelves tracked, modified files; working dir returns to the last commit

git stash push -m "half-done login refactor"
# Same, but with a label so you remember what it is later

# ...fix the urgent bug on another branch, commit it, then come back...

git stash pop
# Reapply the most recent stash and remove it from the stack

2 pop vs apply, and the stash stack

The stash is a stack — you can have several. pop reapplies and removes; apply reapplies but keeps the stash (useful to apply the same shelved work to more than one branch).

git stash list
# stash@{0}: On feature: half-done login refactor
# stash@{1}: WIP on main: a1b2c3 Earlier shelf

git stash apply stash@{1}   # reapply a SPECIFIC stash, keep it on the stack
git stash pop stash@{1}     # reapply that one and drop it

git stash show -p stash@{0} # view the diff a stash contains before applying
git stash drop stash@{1}    # delete one stash without applying it
git stash clear             # ⚠️ delete ALL stashes
⚠️ pop can hit a conflict if the branch moved since you stashed. If it does, the stash is not dropped — resolve the conflict, then git stash drop manually once you're happy.

3 Stashing untracked and ignored files

By default git stash only shelves tracked files. Brand-new (untracked) files stay behind, which surprises people. Use flags to include them:

git stash -u
# Also stash UNTRACKED files (new files Git doesn't know about yet)

git stash -a
# Also stash untracked AND ignored files (everything)

git stash -p
# Interactively choose which hunks to stash (like git add -p)

git stash --keep-index
# Stash only what's NOT staged — keep your staged changes in place

4 Turning a stash into a branch

If you stashed work and the branch has since moved a lot, applying can be messy. git stash branch creates a new branch from the commit you were on when you stashed, then applies the stash there cleanly.

git stash branch recover-login stash@{0}
# New branch "recover-login" from the original base, stash applied, stash dropped
💡 Stash is for temporary shelving — minutes to hours. For anything you want to keep for days, make a real commit on a branch (even a scrappy "wip" commit you'll later squash). Stashes are easy to forget and have no branch name to remind you.
