Attention, transformers, reinforcement learning, and where deep learning is headed.

1 Attention mechanisms

RNNs process a sequence step by step, which is slow to parallelize and still struggles with very long-range dependencies even with LSTM/GRU gating. Attention solves this differently: instead of compressing an entire sequence into one fixed hidden state, attention lets a model look back at every position in the input and learn how much "weight" to give each one when producing a given output.

Concretely, attention computes a weighted sum over all input representations, where the weights (how relevant each input position is to the current output) are themselves learned via a compatibility score between queries, keys, and values — the now-famous Q/K/V formulation.

2 Transformer networks

The 2017 paper "Attention Is All You Need" introduced the Transformer, which drops recurrence entirely and builds a network purely from self-attention layers (where a sequence attends to itself) plus feedforward layers, stacked repeatedly. Because there's no step-by-step recurrence, all positions in a sequence can be processed in parallel during training — a massive speed advantage on modern GPU/TPU hardware compared to RNNs.

  • Self-attention — lets every token in a sequence directly attend to every other token in a single step, regardless of distance, sidestepping the vanishing-gradient-over-many-steps problem RNNs face.
  • Multi-head attention — runs several attention computations in parallel ("heads"), each free to learn a different kind of relationship (e.g. one head might track grammatical subject-verb agreement, another might track coreference).
  • Positional encoding — since self-attention has no inherent sense of order, a positional signal is added to each token's representation so the model knows where in the sequence it sits.

Transformers are the architecture behind essentially all modern large language models (GPT, BERT, and their successors), as well as state-of-the-art vision models (Vision Transformers) and multimodal systems.

3 Reinforcement learning (and deep RL)

Reinforcement learning (RL) is a different paradigm from the supervised learning covered so far: an agent interacts with an environment, taking actions and receiving rewards, with the goal of learning a policy — a strategy for choosing actions — that maximizes cumulative reward over time. There's no fixed labeled dataset; the agent learns from the consequences of its own actions, including delayed consequences.

Deep RL uses a neural network to represent the policy and/or the value function (how good a given state/action is), making RL practical in environments too large to tabulate exhaustively — e.g. DeepMind's AlphaGo and AlphaZero (board games), and RL-based fine-tuning techniques like RLHF (Reinforcement Learning from Human Feedback) used to align large language models with human preferences.

4 Applications across domains

  • Computer Vision (CV) — image classification, object detection, semantic segmentation, facial recognition, medical image analysis (e.g. tumor detection in radiology scans), autonomous vehicle perception.
  • Natural Language Processing (NLP) — machine translation, text summarization, question answering, chatbots and conversational AI, sentiment analysis, code generation.
  • Healthcare — diagnostic image analysis (X-rays, MRIs, pathology slides), drug discovery (predicting molecular properties), genomics (variant calling, protein structure prediction such as AlphaFold), personalized treatment risk prediction.

5 Current trends and future directions

  • Foundation models and scale — very large models pre-trained on broad data, then adapted (fine-tuned or prompted) to many downstream tasks, rather than training a fresh model per task.
  • Multimodal models — single models that jointly process text, images, audio and video rather than one modality at a time.
  • Efficient/edge deep learning — model compression, quantization, and distillation techniques to run capable models on phones and embedded devices with limited compute and power.
  • Explainability and interpretability — growing emphasis on understanding why a deep model made a given prediction, especially critical in healthcare, finance, and other high-stakes domains.
  • Alignment and safety — techniques (like RLHF, red-teaming, constitutional methods) to make powerful models behave in line with human intent and values as capability scales up.
💡 Exam framing to remember: attention/transformers solved the parallelization and long-range-dependency limits of RNNs; deep RL extended neural networks beyond supervised learning into sequential decision-making; and the current frontier is less about new core architectures and more about scale, efficiency, multimodality, and alignment.
