🖼️ Convolutional Neural Networks (CNNs) Intermediate

The architecture that made deep learning dominant in computer vision.

1 Why not just use a plain dense network on images?

A 224×224 color image has 224 × 224 × 3 ≈ 150,000 pixel values. Feeding that into a fully-connected layer would need a weight for every pixel-to-neuron connection — tens of millions of parameters in the very first layer alone, with no notion that nearby pixels are related. CNNs fix this with two ideas: local connectivity (a neuron only looks at a small patch of the image, not the whole thing) and weight sharing (the same small set of weights — a "filter" — slides across the entire image, so the network does not need separate weights for every position).

2 Convolutional layers

A convolutional layer slides a small learnable filter (kernel), e.g. 3×3 or 5×5 pixels, across the input, computing a dot product at each position to produce a single output value. The result is a feature map — a 2D grid showing where in the image that filter's pattern fired strongly. A layer uses many filters in parallel, each learning to detect a different low-level pattern (edges, color blobs, textures in early layers; eyes, wheels, fur patterns in deeper layers).

  • Stride — how many pixels the filter moves between applications. A stride of 2 skips every other position, shrinking the output.
  • Padding — adding a border of zeros around the input so the filter can be centered on edge pixels too, controlling whether the output shrinks ("valid") or stays the same size ("same").
  • Receptive field — the region of the original input that ultimately influences one neuron's value; it grows larger in deeper layers as convolutions stack.

3 Pooling layers

Pooling downsamples a feature map, reducing its spatial size (and therefore computation) while keeping the most important signal. Max pooling (the most common choice) takes the largest value in each small window (e.g. 2×2), discarding the rest. This also gives the network a degree of translation invariance — a feature detected slightly off-position still survives pooling.

4 Fully connected layers

After several convolution + pooling stages compress the image into a compact set of high-level feature maps, those maps are flattened into a single vector and fed into one or more fully connected (dense) layers — the same kind of layer used in a plain ANN — which combine the extracted features into a final classification decision, usually ending in a softmax layer over the target classes.

5 A simple CNN pipeline

Each conv+pool stage shrinks the spatial size while growing the number of feature channels — trading pixel resolution for learned semantic depth — until the representation is compact enough for the fully connected classifier at the end.

6 Transfer learning and fine-tuning

Training a large CNN from scratch needs millions of labeled images and serious compute. Transfer learning sidesteps this by reusing a network already trained on a huge dataset (e.g. ImageNet) for a new, related task:

  • Feature extraction — freeze the pre-trained convolutional base (it already knows general visual features like edges, textures, shapes) and train only a new, small classification head on top for your specific classes. Fast, needs little data.
  • Fine-tuning — after feature extraction, unfreeze some of the later convolutional layers too and continue training at a low learning rate, letting the network slightly adapt its higher-level features to the new domain.
💡 Earlier convolutional layers learn very general features (edges, colors) that transfer well across almost any visual task. Later layers learn task-specific features — that's why fine-tuning typically only unfreezes the later layers, not the earliest ones.
