🔁 Recurrent Neural Networks (RNNs) Intermediate

The architecture family built for sequences — text, audio, and time series.

1 Why CNNs and plain ANNs aren't enough for sequences

Feedforward networks (plain ANNs and CNNs) assume every input is independent and fixed-size. But language, audio and sensor readings are sequential — the meaning of a word depends on the words before it, and a sensor reading depends on the trend leading up to it. A network needs some form of memory to use that context.

2 Structure and function of an RNN

A Recurrent Neural Network processes a sequence one element at a time, maintaining a hidden state vector that acts as a running summary of everything seen so far. At each time step t, the same set of weights is reused to combine the current input xₜ with the previous hidden state hₜ₋₁:

h_t = f(W_xh · x_t + W_hh · h_(t-1) + b)
y_t = g(W_hy · h_t + b_y)

Because the same weights (W_xh, W_hh, W_hy) are reused at every time step, an RNN can handle sequences of any length with a fixed number of parameters — unlike a feedforward network, which would need a different set of weights for every possible sequence length.

3 Unrolled through time

"Unrolling" is a way of visualizing one RNN cell applied repeatedly — it is literally the same set of weights drawn once per time step, with the hidden state flowing from each step into the next. This is also how an RNN is trained: backpropagation through time (BPTT) unrolls the network for the length of the sequence and runs ordinary backpropagation across that unrolled graph.

4 The vanishing gradient problem, and why LSTM/GRU exist

A plain ("vanilla") RNN struggles with long-range dependencies: during BPTT, gradients are repeatedly multiplied by the same weight matrix at every time step going backwards. If that multiplication tends to shrink the gradient, it can vanish to near zero after enough steps — the network effectively "forgets" anything that happened many steps earlier.

  • LSTM (Long Short-Term Memory) — adds a separate cell state alongside the hidden state, plus three learned gates: a forget gate (what to discard from the cell state), an input gate (what new information to add), and an output gate (what to expose as the hidden state). These gates let gradients flow through the cell state largely unchanged across many time steps, directly addressing vanishing gradients.
  • GRU (Gated Recurrent Unit) — a simplified alternative with only two gates (update and reset) and no separate cell state. It merges some of LSTM's mechanics, trains faster and uses fewer parameters, and performs comparably on many tasks.

5 Applications

  • Natural Language Processing — language modeling, machine translation, sentiment analysis, text generation (largely superseded by Transformers today, but foundational to the field).
  • Speech recognition — converting an audio waveform (a sequence of samples) into a sequence of phonemes/words.
  • Time-series analysis — stock price forecasting, sensor/IoT anomaly detection, weather prediction — anywhere the order and recency of past values carries predictive information.
