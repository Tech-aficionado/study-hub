🧩 Neural Networks and Backpropagation Beginner → Intermediate

How a feedforward network computes a prediction, and how it learns from its mistakes.

1 Structure and function of an ANN

An artificial neural network is organized into layers of neurons: an input layer (one unit per input feature), one or more hidden layers, and an output layer (one unit per predicted value or class). Every neuron in one layer is typically connected to every neuron in the next (a "fully connected" or "dense" layer).

Each neuron computes two things in sequence:

  1. A weighted sum: z = w1·x1 + w2·x2 + ... + wn·xn + b, where each w is a learnable weight and b is a learnable bias.
  2. An activation function a = f(z) applied to that sum, introducing the non-linearity that lets the network model complex, non-linear relationships. Without it, stacking layers would collapse into one big linear function no matter how many layers you add.

2 The feedforward pass

A feedforward network passes information in one direction only — input → hidden layer(s) → output — with no loops or feedback connections (that's what distinguishes it from a recurrent network, covered later). Each layer's output becomes the next layer's input.

💡 "Feedforward" just means the data flows forward only. It says nothing about depth — a feedforward network can still have many hidden layers (that's what makes it "deep").

3 The backpropagation algorithm

Training a network means finding the weights that minimize the loss function. Backpropagation is the algorithm that computes, for every single weight in the network, exactly how much a tiny change in that weight would change the final loss — its gradient.

It works backwards from the output using the calculus chain rule:

  1. Forward pass — compute the prediction and the loss, caching every intermediate value along the way.
  2. Backward pass — starting at the loss, propagate the error signal backwards layer by layer. At each layer, the chain rule lets you express "how much did this weight contribute to the final error" in terms of the error already computed one layer downstream, so the computation is reused rather than redone from scratch for every weight.
  3. Weight update — each weight is nudged a small step opposite to its gradient: w ← w − η · ∂Loss/∂w, where η (eta) is the learning rate.

This triple (forward pass, backward pass, update) is one training step, repeated over many batches and epochs until the loss stops meaningfully decreasing. Without backpropagation's reuse of intermediate results, computing gradients for millions of weights individually would be computationally infeasible — it's the single algorithm that made training deep networks practical.

Gradient descent is the optimizer that uses the gradients; backpropagation is the method that computes them efficiently. They are often spoken of together but are not the same thing.

5 Weight initialization

Weights can't start at zero (every neuron in a layer would compute the identical gradient and the network could never break symmetry) or be drawn too large/small (gradients would explode or vanish as they propagate through many layers). Two widely used schemes size the initial random weights based on the number of inputs/outputs of a layer:

  • Xavier/Glorot initialization — scales weights based on the number of input and output units; designed for sigmoid/tanh activations to keep the variance of activations roughly stable across layers.
  • He initialization — scales weights based on the number of input units only, with a larger variance tuned specifically for ReLU-family activations (since ReLU zeroes out roughly half its inputs).

6 Regularization techniques

A network with enough capacity can simply memorize the training set (overfitting) instead of learning generalizable patterns. Common fixes:

  • L1/L2 weight regularization — adds a penalty term to the loss proportional to the size of the weights, discouraging any single weight from growing too large. L1 tends to push weights to exactly zero (sparsity); L2 ("weight decay") shrinks them smoothly.
  • Dropout — during training, randomly "switches off" a fraction of neurons on each forward pass, forcing the network to not rely on any single neuron and effectively training an ensemble of sub-networks.
  • Early stopping — monitor validation loss during training and stop once it starts increasing, even if training loss keeps falling.
  • Batch normalization — normalizes the inputs to each layer to have stable mean/variance during training, which also has a mild regularizing side effect and speeds up convergence.
  • Data augmentation — artificially expands the training set (crops, flips, noise) so the network sees more variation and memorizes less.
