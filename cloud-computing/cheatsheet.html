📋 Quick Reference

Key terms, service models, deployment models and hypervisors — at a glance.

1 Service models (one-liners)

TermDefinition
IaaSRent raw infrastructure (VMs, storage, networking) — you manage the OS up
PaaSRent a ready-to-use platform (OS + runtime) — you deploy just your app code
SaaSRent a complete, ready-to-use application — you just bring your data
DaaSRent a virtual desktop, delivered and managed from the cloud
FaaS / ServerlessRun individual functions on demand — no server to manage at all
MaaSOutsourced monitoring of infrastructure/app health and uptime
CaaS (Communication)Outsourced voice/video/messaging infrastructure

2 Deployment models

ModelWho uses it
PublicAnyone — shared, provider-owned infrastructure
PrivateOne organization — dedicated infrastructure
CommunityA group of orgs with shared compliance/mission needs
HybridMix of private + public, workloads move between them

3 Virtual machine types

TypeVirtualizes
System VMAn entire machine, with a full guest OS
Process VMA single process/application's runtime (e.g. JVM)

CharacteristicMeaning
